# Guide d'accueil – Techniciens

Guide de triage à l'accueil de la pharmacie (PL67). Le technicien choisit la condition, répond aux questions, et le guide indique la marche à suivre : pharmacien sur place, rendez-vous, infirmière, référence, etc.

- Fonctionne sur ordinateur, téléphone et tablette, même sans internet.
- Installable : sur téléphone, « Ajouter à l'écran d'accueil » ; sur ordinateur (Chrome/Edge), « Installer l'application ».
- Aucune donnée de patient n'est enregistrée.

Les conditions, priorités et questions se trouvent dans `index.html`, dans le bloc `CATEGORIES`.

Outil interne : il ne remplace pas le jugement du pharmacien.
